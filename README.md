## Balancing Puzzle

This is a short puzzle I created in java to learn java and just for fun.
The puzzle is as follows.
<br><br>
Given there are the 8 values.
and there are 8 functions that convert 2 values to 2 other values, as well as 1 function that converts 4 values into 4 other values.
And that you may only use those functions to modify the values
Balance the values so that they are as equal as possible
<br><br>
These are the values<br>
A Alpha<br>
B Beta<br>
D Delta<br>
E Epsilon<br>
G Gamma<br>
I Iota<br>
L Lambda<br>
O Omega<br>
<br><br>
These are the folding functions<br>
A O	==>	B E<br>
L B	==> A D<br>
D B	==>	E I<br>
A E	==>	D G<br>
E G	==>	I O<br>
D I	==>	G L<br>
I L	==>	B O<br>
G O	==>	A L<br>
<br><br>
This is the swapping function<br>
A B G I ==> D E L O<br>
